# Data Formats

This document describes the JSON data formats used in ZapSquad.

## Tile Definition (`mods/tiles/{id}/definition.json`)

```json
{
  "id": "drum_gri",
  "name": "DRUM GRI",
  "walkable": true,
  "blocksVision": false,
  "damagePerTurn": 0,
  "tileType": "PATH",           // "TILE" | "PATH" | "BRIDGE"
  "terrainType": "LAND",        // "LAND" | "WATER"
  "bridgeAssetId": "bridge_80px", // Optional: bridge to use when this path crosses water
  "variations": 15,             // Number of sprite variations (1-15)
  "createdAt": "2026-02-20T09:35:59.500Z",
  "updatedAt": "2026-02-20T09:35:59.500Z"
}
```

### Tile Types

| tileType | Description | Layer | Connectivity |
|----------|-------------|-------|--------------|
| `TILE`   | Base terrain (grass, dirt, ocean) | Background | Variation-based |
| `PATH`   | Walkable paths (roads, bridges) | VFX/Foreground | 4-bit connectivity (N=8,S=4,W=2,E=1) |
| `BRIDGE` | Bridge tiles (drawn under paths over water) | Foreground | 4-bit connectivity |

### Terrain Types

| terrainType | Description | Used For |
|-------------|-------------|----------|
| `LAND`      | Solid ground | Terrain, roads |
| `WATER`     | Water/liquid | Ocean, river |

### Auto-Bridge Logic

When a PATH tile with `terrainType: "LAND"` is placed over a tile with `terrainType: "WATER"`, the engine automatically generates a bridge using the `bridgeAssetId`.

## Baked Manifest (`assets/manifest.json`)

Generated by `tools/bake-atlases.ts` from individual tile definitions.

```json
{
  "version": 2,
  "spriteSize": 128,
  "maxFrames": 8,
  "characters": {
    "carnat_test": {
      "id": "carnat_test",
      "name": "CARNAT TEST",
      "atlas": "characters/carnat_test.png",
      "atlasWidth": 1024,
      "atlasHeight": 1536,
      "spriteSize": 128,
      "animations": {
        "idle_east": { "row": 0, "frames": 1, "loop": true },
        "walk_east": { "row": 8, "frames": 4, "loop": true }
      }
    }
  },
  "tiles": {
    "drum_gri": {
      "id": "drum_gri",
      "name": "DRUM GRI",
      "atlas": "tiles/drum_gri.png",
      "atlasWidth": 1920,
      "atlasHeight": 1152,
      "spriteSize": 128,
      "variations": 15,
      "hasTransitions": true,
      "tileType": "PATH",
      "terrainType": "LAND",
      "bridgeAssetId": "bridge_80px"
    }
  },
  "weapons": { ... }
}
```

## Sprite Manifest (`assets/assets.json`)

zap-engine format for sprite lookups. Generated from manifest.json.

```json
{
  "atlases": [
    { "name": "characters_carnat_test", "cols": 8, "rows": 12, "path": "characters/carnat_test.png" },
    { "name": "tiles_iarba", "cols": 3, "rows": 9, "path": "tiles/iarba.png" }
  ],
  "sprites": {
    "iarba_0": { "atlas": 12, "row": 0, "col": 0 },
    "iarba_1": { "atlas": 12, "row": 0, "col": 1 },
    "iarba_3": { "atlas": 12, "row": 1, "col": 0 }
  },
  "sounds": {}
}
```

### Tile Sprite Index Convention

For tiles with transitions:
- **Row 0**: Base variations (indices 0 to variations-1)
- **Row 1**: North transitions (indices variations to 2*variations-1)
- **Row 2**: NE transitions
- **Row 3**: East transitions
- **Row 4**: SE transitions
- **Row 5**: South transitions
- **Row 6**: SW transitions
- **Row 7**: West transitions
- **Row 8**: NW transitions

Formula: `sprite_index = row * variations + variation`

## Level Format (`mods/levels/{name}.json`)

LDtk-compatible JSON format.

```json
{
  "levels": [{
    "identifier": "harta_cu_portal",
    "pxWid": 2560,
    "pxHei": 1920,
    "layerInstances": [
      {
        "__identifier": "Tiles",
        "__type": "Tiles",
        "__gridSize": 128,
        "gridTiles": [
          {
            "px": [0, 0],
            "t": 12345,
            "src": "iarba"
          }
        ]
      },
      {
        "__identifier": "Entities",
        "__type": "Entities",
        "__gridSize": 128,
        "entityInstances": [
          {
            "__identifier": "Character",
            "px": [960, 960],
            "fieldInstances": [
              { "__identifier": "body_def_id", "__value": "carnat_test" },
              { "__identifier": "tag", "__value": "player" }
            ]
          }
        ]
      }
    ]
  }]
}
```

### Grid Tile Fields

| Field | Description |
|-------|-------------|
| `px`  | Position [x, y] in pixels (top-left corner) |
| `t`   | Seed value for variation selection |
| `src` | Asset ID (references manifest.tiles) |

### Entity Fields

| Field | Description |
|-------|-------------|
| `px` | Position [x, y] in pixels (center-based) |
| `fieldInstances` | Custom fields (body_def_id, weapon_def_id, script, tag, etc.) |

## Layer Rendering Order

The WASM renderer uses 6 layers (zap-engine RenderLayer enum):

| Layer | Value | Contents |
|-------|-------|----------|
| Background | 0 | Base terrain (land, water) |
| Terrain | 1 | Transitions (computed), rivers |
| Objects | 2 | (unused for tiles) |
| Foreground | 3 | Bridges (auto-generated) |
| VFX | 4 | Ground paths (roads) |
| UI | 5 | Characters & objects |

### Computed Tile Features

1. **Transitions**: Auto-generated when different terrain types meet. Dominant tile (higher asset_id) projects its transition onto neighbors.

2. **Bridges**: Auto-generated when a ground path (terrainType=LAND) crosses water (terrainType=WATER). Uses the path's `bridgeAssetId`.

3. **Path Connectivity**: 4-bit bitmask based on neighboring paths of the same type.
   - N=8, S=4, W=2, E=1
   - Sprite index = connectivity bits (0-14)
